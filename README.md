# Hi, I'm Syed Muhammad Hussnain Raza

### Software Developer | BS Computer Science Student | Full-Stack & Backend Development

I'm a 7th-semester BS Computer Science student at **COMSATS University Islamabad, Lahore Campus**, with hands-on experience in software development through academic and industrial projects.

Currently, I'm working on my **industrial Final Year Project at HazelSoft** as a Software Developer and Team Lead. Our team is developing **SkillPath**, an AI-based skill gap analysis platform.

My current focus is on **backend and full-stack development**, particularly with **C#/.NET, ASP.NET Core, React, TypeScript, Python, and FastAPI**. Alongside software development, I am exploring **Artificial Neural Networks, Deep Learning, contrastive learning, and cybersecurity applications of machine learning**.
